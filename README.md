# Monolith

App Android di Christian "Xoushal" Vedovi: agenda, chat, posizione in tempo reale e chiamate con gli amici.

Ogni push su `main` genera l'APK nelle *Releases*.

Groups and shards: group info with admins and settings, invite links (monolith://entra/<code> from https://monolith.support/#entra/<code>), and shards for everyone made by accounts verified as developers.
